This is the first post on the technical side of the site. Posts here will cover AI/ML topics, machine vision, NLP, and notes from my MSc coursework at UL.

## How to add a new post

Create a new markdown file in `_posts/` named `YYYY-MM-DD-title.md`, with a title, tags, and excerpt in the front matter at the top (like this file has), then write the post in markdown below it. Push to GitHub and it publishes automatically.

```markdown
---
title: "My post title"
tags: [python, ml]
excerpt: "One line summary shown in the listing."
---

Post content goes here.
```

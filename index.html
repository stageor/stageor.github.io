Projects

Spotify data platform on Azure

ADF · Databricks · Unity Catalog · Delta Live Tables · PySpark · Azure SQL DB

An end-to-end build on a medallion architecture. Azure SQL Database and a GitHub-hosted file set feed dynamic, parameterised Data Factory pipelines into the bronze layer, with incremental loads and backfilling. Databricks, with Unity Catalog, Spark Structured Streaming, and Autoloader, cleans the data into the silver layer, where metadata-driven notebooks build a star schema with slowly changing dimensions. Delta Live Tables shape the gold layer, served through a SQL warehouse.

CDC lakehouse with dbt and Airflow

Databricks · dbt · Apache Airflow · Delta Lake · CDC

A production-style lakehouse pulling from an AWS S3 data lake and an agentic Postgres database that stakeholders can query directly in natural language. Change data capture lands updates straight into Delta tables in the bronze layer; dbt builds a One Big Table with quality checks and Jinja templating in the silver layer, then a star schema with slowly changing dimensions in the gold layer. Apache Airflow orchestrates the pipeline, deployed and version-controlled on GitHub.

Agentic data agent

LangGraph · LangChain · Pydantic · Python

A multi-agent system that lets non-technical stakeholders ask for data in plain language. A parent agent routes requests to two sub-agents: a stateful SQL analyst that curates the question, adds database context, generates and safety-checks a query, then runs it; and a ReAct-based ETL analyst that loops through a Python toolkit to extract, transform, and load data. Routes between LLMs by task and checks outputs with an LLM-as-judge step.

Real-time ride-booking pipeline

Kafka · Event Hub · Spark Structured Streaming · ADF · FastAPI

A streaming pipeline modelled on a ride-booking app. A FastAPI web app publishes ride-confirmation events to an Event Hub in a producer/consumer pattern, picked up by Spark Structured Streaming. Azure Data Factory handles metadata-driven bulk loads into the bronze layer; the silver layer builds a streaming One Big Table; the gold layer streams out a star schema with slowly changing dimensions.

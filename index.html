Selected work

Spotify data platform on Azure

ADF · Databricks · Unity Catalog · Delta Live Tables · PySpark · Azure SQL DB

An end-to-end build on a medallion architecture. Azure SQL Database and a GitHub-hosted file set feed dynamic, parameterised Azure Data Factory pipelines into the bronze layer, with incremental loads and backfilling. Azure Databricks, with Unity Catalog, Spark Structured Streaming, and Autoloader, cleans the data into the silver layer, where metadata-driven notebooks (templated with Jinja2) build a star schema with slowly changing dimensions. Delta Live Tables shape the gold layer, served through a SQL warehouse. Git branching and Databricks Asset Bundles handle CI/CD.

Agentic data agent

LangGraph · LangChain · Pydantic · Python

A multi-agent system that lets non-technical stakeholders ask for data in plain language. A parent data agent routes each request to one of two sub-agents: a stateful SQL analyst that curates the question, adds database context, generates and safety-checks a SQL query with an LLM, then runs it; and a ReAct-based ETL analyst that loops through a Python toolkit to extract, transform, and load data. Routes between high- and low-capability LLMs by task, uses Pydantic models for structured state, and checks outputs with an LLM-as-judge step.
